# nm-messenger

Простой веб-чат в реальном времени: FastAPI + WebSocket на сервере, чистый HTML/JS в браузере.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app:app --reload
```

Открой http://127.0.0.1:8000, введи имя и пиши. Открой вторую вкладку под другим именем — сообщения приходят мгновенно.

Чтобы зайти с телефона или другого компьютера в той же сети, запусти с `--host 0.0.0.0` и открой `http://<IP-этого-Mac>:8000`.

## Что умеет

- общий чат с мгновенной доставкой сообщений;
- список тех, кто онлайн;
- отправка фото (кнопка 📎): фото уменьшается до 1600px и сохраняется в папку `uploads/`;
- последние 100 сообщений приходят новым участникам (хранятся в памяти, пропадают при перезапуске сервера);
- автоматическое переподключение при обрыве связи;
- светлая и тёмная тема.
